LUFORA — E-commerce de tecnología

Cofundador y desarrollador · Full Stack

Tienda en línea de tecnología de mi emprendimiento, donde asumo el ciclo completo del producto. El backend es una API REST con Java 25, Spring Boot 3 y MySQL 8: 20 endpoints para productos, marcas y categorías, con búsqueda por filtros dinámicos (JPA Specifications), paginación y validación de datos.

  • Seguridad con Spring Security y JWT: filtro de autenticación propio y usuarios con roles.
  • Código organizado por módulos de negocio con DTOs, mappers y manejo global de errores.
  • Migraciones con Flyway, base de datos en Docker Compose y documentación con Swagger / OpenAPI.
  • Frontend en React, TypeScript y Vite: catálogo con filtros, carrito (Context API), checkout y diseño responsivo.
