PRIMARKET

Experiencia profesional · Junio – Diciembre 2025 · 1.040 horas certificadas

Trabajé como Desarrollador Backend Java — Spring Boot en la plataforma e-commerce Primarket, en un equipo remoto desde Buenos Aires. Desarrollé más de 15 endpoints REST con Spring Boot, JPA/Hibernate y MySQL, aplicando principios SOLID y patrones de diseño. Implementé autenticación y autorización con JWT, protegiendo los servicios críticos y la carga y transferencia de archivos entre el frontend en React y el backend. Desarrollé el flujo de verificación de cuenta por correo electrónico (generación del código, envío, validación y expiración) y construí un chatbot interno de soporte que redujo cerca de un 30 % las consultas manuales del equipo. Documenté la API con Swagger / OpenAPI y JavaDoc, y trabajé con Git y GitHub bajo metodologías ágiles y revisiones de código.

SOUNDAL

Proyecto académico SENA · Agosto 2023 – Febrero 2024

SOUNDAL es un sistema de gestión para una veterinaria, desarrollado en Java sobre NetBeans y conectado a una base de datos MySQL. Diseñé el modelo relacional para la gestión integral de mascotas y propietarios, e implementé operaciones CRUD para consulta, edición y almacenamiento de la información, asegurando su integridad y disponibilidad.

E-COMMERCE PROPIO

Proyecto personal · 2026 – Actualidad

Plataforma de e-commerce que desarrollo para mi emprendimiento tecnológico, asumiendo el ciclo completo del producto. El backend está construido con Spring Boot sobre MySQL: modelo de datos, catálogo de productos, carrito y flujo de compra. El frontend está desarrollado en React con diseño responsivo. Yo defino la arquitectura, el modelo de datos y las decisiones técnicas del proyecto de principio a fin.
